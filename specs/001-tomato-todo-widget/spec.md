## 用户场景与测试 *(必填)*

### 用户故事 1 - 番茄时钟计时器 (优先级: P1)

用户需要一个番茄时钟来帮助管理工作和休息时间。时钟显示数字时间格式,可以通过开始、暂停、停止按钮控制。倒计时结束后会显示全屏提示。

**优先级原因**: 番茄时钟是核心功能,是用户使用此工具的主要目的,必须首先实现才能提供价值。

**独立测试**: 可以通过启动应用、设置时间、点击开始、等待倒计时、观察提示来完整测试整个计时器流程。

**验收场景**:

1. **给定** 应用启动, **当** 用户点击停止按钮或首次启动时, **那么** 显示时间设置界面,图标显示为开始状态
2. **给定** 时间已设置, **当** 用户点击开始图标, **那么** 开始倒计时,图标切换为暂停,时间逐秒递减
3. **给定** 正在倒计时, **当** 用户点击暂停图标, **那么** 倒计时暂停,图标切换为开始
4. **给定** 已暂停, **当** 用户点击开始图标, **那么** 从暂停处继续倒计时
5. **给定** 倒计时进行中, **当** 时间归零, **那么** 渐隐柔和显示全屏"时间到"提示2秒后自动渐隐,或用户点击或按键后立即渐隐
6. **给定** 倒计时进行中或暂停, **当** 用户点击停止图标, **那么** 倒计时终止,重置为初始设置状态
7. **给定** 倒计时归零并显示提示, **当** 用户点击开始下一个番茄, **那么** 自动设置为25分钟工作倒计时(工作模式)
8. **给定** 工作番茄倒计时归零, **当** 开始休息, **那么** 自动设置为5分钟休息倒计时(休息模式)
9. **给定** 休息倒计时归零, **当** 开始下一个周期, **那么** 自动设置为25分钟工作倒计时,循环往复

### 用户故事 2 - TodoList任务管理 (优先级: P2)

用户需要一个简单的任务列表来记录待办事项。任务可以添加、完成、删除、修改,并按创建时间倒序显示。

**优先级原因**: 任务管理是次要功能,但在时钟基础上增强了工具的实用性,配合时钟使用形成完整的工作流。

**独立测试**: 可以通过添加任务、标记完成、删除任务、修改任务内容来测试所有任务管理功能,无需依赖时钟功能。

**验收场景**:

1. **给定** 应用打开, **当** 用户查看TodoList区域, **那么** 最多显示5条任务记录,超出部分可向下滚动查看
2. **给定** TodoList第一行输入框, **当** 用户输入任务文本并按回车, **那么** 新任务添加到列表顶部,输入框清空
3. **给定** 任务列表中有多个任务, **当** 用户查看列表顺序, **那么** 最新创建的任务显示在最上面(倒序)
4. **给定** 任务列表中的任务, **当** 用户点击左侧圆形完成图标, **那么** 任务添加删除线,移动到列表底部,图标变为已完成状态
5. **给定** 已完成的任务, **当** 用户再次点击完成图标, **那么** 删除线移除,任务恢复到之前创建时的位置
6. **给定** 任务列表中的任务, **当** 用户鼠标悬停在任务上, **那么** 该任务记录高亮显示
7. **给定** 任务列表中的任务, **当** 任务文本超过20个字符, **那么** 仅显示前20个字符,鼠标悬浮时通过tooltip显示完整内容
8. **给定** TodoList输入框, **当** 用户输入超过100个中文字符, **那么** 系统阻止继续输入或提示达到最大长度
9. **给定** 任务列表中的任务, **当** 用户右键点击任务, **那么** 弹出菜单显示"删除"、"修改"、"标记完成"选项
10. **给定** 右键菜单打开, **当** 用户选择"删除", **那么** 任务从列表中移除
11. **给定** 右键菜单打开, **当** 用户选择"修改", **那么** 任务文本变为可编辑状态
12. **给定** 右键菜单打开, **当** 用户选择"标记完成", **那么** 行为与点击完成图标相同
13. **给定** 任务数量超过20条, **当** 用户查看任务列表, **那么** 显示分页控件,每页最多显示20条任务

### 用户故事 3 - 窗口布局和交互 (优先级: P3)

用户需要自定义窗口位置和大小,以便小组件能够适应不同的工作环境。窗口可以置顶、靠边、调整大小。

**优先级原因**: 窗口管理是辅助功能,虽然提升用户体验但不是核心价值,可以在核心功能稳定后完善。

**独立测试**: 可以通过拖动窗口、调整大小、点击置顶按钮来测试所有窗口交互功能,不依赖时钟和任务功能。

**验收场景**:

1. **给定** 应用窗口打开, **当** 用户查看布局, **那么** 上方显示数字番茄时钟,下方显示TodoList任务列表
2. **给定** 应用窗口打开, **当** 用户查看时钟控制, **那么** 看到开始/暂停图标(二者互斥,只显示一个)和停止图标
3. **给定** 应用窗口, **当** 用户启用置顶功能, **那么** 窗口保持在其他窗口之上
4. **给定** 应用窗口, **当** 用户禁用置顶功能, **那么** 窗口可以覆盖在其他窗口之下
5. **给定** 应用窗口靠近屏幕边缘, **当** 用户使用靠边功能, **那么** 窗口自动对齐到屏幕边缘
6. **给定** 应用窗口, **当** 用户拖动窗口边缘或角落, **那么** 窗口大小可以调整
7. **给定** 应用窗口大小改变, **当** 窗口缩小, **那么** TodoList区域自适应剩余空间,时钟显示保持清晰
8. **给定** 应用窗口, **当** 用户尝试缩小窗口超过最小尺寸, **那么** 窗口停止缩小,保持最小高度(时钟+2行TodoList)和最小宽度(时钟可见)

### 边界情况

- 应用关闭后重新打开时: 保留所有数据和状态,从SQLite数据库恢复
- 倒计时进行中应用崩溃或意外关闭: 从数据库恢复数据,恢复时保持崩溃时的状态
- TodoList任务数量超过几百条: 超过20条时使用分页显示,每页20条
- 用户输入非常长的任务文本: 单条任务最多100个中文字符,显示时截取前20个字符,鼠标悬浮时通过tooltip显示完整内容
- 多个实例同时运行: 不支持多实例,应用启动时检测并阻止第二个实例运行
- 系统休眠或锁定时: 倒计时继续计时,不休眠暂停
- 全屏提示显示时用户按键: 接受任何键盘按键操作后立即渐隐退出提示

- **FR-002**: 系统必须提供时间设置界面,允许用户设置倒计时时长
- **FR-003**: 系统必须提供开始、暂停、停止三个控制按钮,开始和暂停互斥显示
- **FR-004**: 系统必须在倒计时归零时显示全屏"时间到"提示
- **FR-005**: 系统必须在全屏提示显示2秒后自动渐隐,或接受用户点击后立即渐隐
- **FR-006**: 系统必须提供TodoList输入框,位于列表第一行
- **FR-007**: 系统必须支持回车键快速添加任务
- **FR-008**: 系统必须按任务创建时间倒序显示(最新在上)
- **FR-009**: 系统必须限制默认显示5条任务,超出部分可滚动查看
- **FR-010**: 系统必须为每个任务提供左侧圆形完成图标
- **FR-011**: 系统必须在任务完成时添加删除线并将任务移动到列表底部
- **FR-012**: 系统必须支持取消完成状态,移除删除线并恢复原位置
- **FR-013**: 系统必须在鼠标悬停任务时高亮显示该任务
- **FR-014**: 系统必须提供右键菜单,包含删除、修改、标记完成选项
- **FR-015**: 系统必须支持窗口置顶功能
- **FR-016**: 系统必须支持窗口靠边对齐功能
- **FR-017**: 系统必须支持窗口大小调整,并设置最小尺寸限制(高度最小是时钟加2行TodoList,宽度最小是时钟可见)
- **FR-018**: 系统必须在窗口大小改变时自适应内部布局
- **FR-019**: 系统必须采用扁平化、去锐利化的UI设计风格(圆角、柔和阴影)
- **FR-020**: 系统必须在倒计时结束后默认按25分钟工作、5分钟休息的模式自动轮询展示
- **FR-021**: 系统必须使用SQLite数据库保存用户的TodoList任务数据和用户偏好设置
- **FR-022**: 系统必须保存番茄时钟的基本使用历史,包括完成的番茄数量、今日和本周统计
- **FR-023**: 系统必须在倒计时结束时仅使用全屏视觉提示,不播放声音
- **FR-024**: 系统必须限制TodoList单条任务最多100个中文字符
- **FR-025**: 系统必须在TodoList显示时只显示任务文本的前20个字符(中英),鼠标悬浮时展示全部内容
- **FR-026**: 系统必须支持TodoList分页功能,当任务超过20条时分页显示
- **FR-027**: 系统必须在全屏提示显示时,接受任何键盘按键操作后渐隐退出
- **FR-028**: 系统必须在系统休眠或锁定时继续计时
- **FR-029**: 系统必须确保仅支持单个实例运行,不允许多个实例同时运行

### 关键实体

- **番茄时钟**: 表示当前的计时器状态,包含设置时长、剩余时间、运行状态(运行/暂停/停止)、开始时间、当前模式(工作/休息)
- **番茄历史记录**: 表示番茄时钟的使用统计,包含完成的番茄数量、今日完成数、本周完成数
- **Todo任务**: 表示一个待办事项,包含任务内容(最多100个中文字符)、创建时间、完成状态、完成时间、在列表中的位置
- **用户偏好**: 表示用户的个人设置,包含默认番茄时长(25分钟)、默认休息时长(5分钟)、窗口位置、窗口大小、置顶状态
- **分页状态**: 表示TodoList的分页信息,包含当前页码、每页数量(20条)、总页数

## 假设

- 用户使用Windows 10及以上操作系统,具有基本的桌面应用操作经验
- 用户理解番茄工作法的基本概念(工作25分钟,休息5分钟)
- 用户不需要多设备同步功能,数据仅存储在本地SQLite数据库
- 应用不需要网络连接即可正常运行
- 用户不需要复杂的任务分类、标签、优先级等功能
- 用户需要基本的番茄时钟统计(今日/本周完成数量),不需要详细的历史数据分析
- 默认番茄时长为25分钟,休息时长为5分钟,可在设置中修改
- 应用采用单一窗口,不需要多窗口支持
- 应用仅支持单实例运行,不允许多个实例同时运行
- 数据存储使用SQLite数据库,自动保存,无需用户手动操作
- 用户偏好静音提醒,不需要声音提示功能
- 窗口最小尺寸由UI布局决定(时钟+2行TodoList高度,时钟可见宽度)
- TodoList任务在20条以内时使用滚动,超过20条时分页显示
- 系统休眠或锁定时倒计时继续计时,不会暂停
- 全屏提示时用户按任意键盘按键都会退出提示
